% Rules the fill obeys (see the contract for the full rulebook):
%   * every %% SLOT marker stays in the filled copy

%     a missing figure is a \figurereceipt line, never a hole
%   * the register speaks directly to the researcher who owns the campaign —
%     no role labels, no committee voice
%   * citations must trace: every external reference's arXiv ID appears
%     in the ledger or a vault card; every cited vault note must exist
%   * NO PAGE CAP — a quiet loop is one page, a rich loop runs three;
%     over-length is a receipt signal, never a truncation

%% SLOT: findings (required — prose, one \finding per adjudication)
% A finding that formulates a problem carries its classic form GENERATED
% from the run's formulation.toml (render_formulation.py + the
% formulation-display skill) — never agent-recalled math.
% A finding that adjudicates an experiment EMBEDS its evidence figures
% (\reportfigure lines from the run's figures.json manifest, rendered via
% render_figures.py — self-contained: run-dir paths don't open across
% machines). A missing or failed figure is a \figurereceipt line — the
% numbers and stamps stay, the report ships.
% In-flight work NAMES expected artifacts (run-id + filename); it never
% embeds, never links.
% Each finding EXPLAINS: what the hypothesis was, in plain language,
% before anything else. Then what was done, what the numbers say, and
% what they mean mechanically. Numbers verbatim + \stamp{...}. A quiet
% loop with no adjudications is an explicit sentence saying so.
