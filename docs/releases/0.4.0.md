version: 0.4.0
date: 2026-10-29
highlights:
  - title: A model picker that knows what you can actually reach
    body: >-
      The picker now probes your connected providers and hides models your
      account can't use — "Show unavailable (N)" brings them back when you
      want to look. Star your favorites, see the recommended model for each
      role, and compare price and latency right in the list. If you pick a
      model that has gone dead, you get a warning with a one-click switch to a
      working one.
  - title: The night engine opens PRs that already passed CI's gates
    body: >-
      Overnight runs now check their work against the same cheap gates CI
      runs (drift, typecheck, the tests the change touched) before opening a
      pull request, so the morning queue is green PRs, not red ones.
  - title: The hub frontdoor listens on loopback only
    body: >-
      The hub's frontdoor now binds to 127.0.0.1 and is reached through the
      fleet tunnel, never the open network. ADR 0037 writes down the trust
      boundaries behind it.
  - title: Skills for every engine
    body: >-
      The amicode skill catalog now reaches every agent engine you run, not
      just the default one — and when a skill can't load, it says so instead
      of quietly going missing.
  - title: Question notifications, fixed
    body: >-
      You no longer get a question or permission notification for the session
      you are already looking at; the ones for your other sessions still
      arrive.
links:
